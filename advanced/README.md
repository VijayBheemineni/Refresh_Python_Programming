# Random Numbers
## General
- Python generates `pseudo` random numbers(Which means its not totally true random number). Its based on seed value. By default Python chooses 'seed' value.

```
# In below code the seed is chosen by Python. 'rand' method returns number between 0 and 1.
>>> import numpy as np
>>> np.random.rand()
0.9513569609499181

# In below code we set 'seed' value. Now who ever uses same seed value same numbers are generated by 'rand'. You can open another terminal, set 'seed' and test out.
>>> import numpy as np
>>> np.random.seed(999)
>>> np.random.rand()
0.8034280400796879
>>> np.random.rand()

# Simulate dice. We use 'randint' method which takes two parameters. 'start', 'end'(exclusive)
>>> import numpy as np
>>> np.random.seed(999)
>>> np.random.randint(1,7)
1
>>> np.random.randint(1,7)
5
>>> np.random.randint(1,7)
6
```
